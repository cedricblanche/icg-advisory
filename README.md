# ICG Advisory

Responsive company website based on the ICG Advisory company presentation.

## Files

- `index.html`: English company and service content.
- `styles.css`: responsive visual design.
- `script.js`: accessible mobile navigation and footer year.
- `.nojekyll`: serves the project as plain static files on GitHub Pages.

## GitHub Pages

Publish from the `main` branch, root directory, in **Settings â†’ Pages â†’ Deploy from a branch**. All links are relative, so the site also works under a project URL.

No build step, packages, tracking, cookies, external fonts or third-party scripts are required. No enquiry form collects or sends visitor data.

## Local preview

Serve this directory with any local static web server, for example `python -m http.server 4173 --bind 127.0.0.1`, then open `http://127.0.0.1:4173`.

## Editing

Edit the text in `index.html`, and colours or layout in `styles.css`. The contact address Nasrbey@gmail.com was confirmed by the project owner. The email link opens the visitor’s email application; it does not send a message automatically. The company presentation is the editorial source; no competitor biographies or credentials are included.
